# CloudPulse Support

CloudPulse is a community-driven open-source project.

## Getting Help

Before requesting help:

1. Read the README and contributing documentation.
2. Check existing GitHub issues for similar questions or problems.
3. Run the latest version of CloudPulse when possible.

## Bug Reports

If CloudPulse behaves unexpectedly, open a GitHub issue and include enough information to reproduce the problem.

Useful information includes:

- Python version
- operating system
- CloudPulse version or commit
- command that was executed
- expected behavior
- actual behavior
- relevant error output

## Feature Ideas

Feature proposals are welcome through GitHub issues. Explain the problem or use case as well as the proposed behavior.

## Security Problems

Do not use public support issues to disclose security vulnerabilities.

Follow the private reporting guidance in `SECURITY.md` instead.

## Community Support

Support is provided on a best-effort basis. CloudPulse does not currently provide guaranteed response times or commercial support.
